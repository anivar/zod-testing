# zod-testing — merged into [zod-skill](https://github.com/anivar/zod-skill)

This skill is no longer maintained separately. Its content — the testing guide,
the Jest/Vitest API reference, and the anti-patterns — now lives in the `zod`
skill, which also covers schema design, parsing, error handling and inference.

Testing schemas was never a separate discipline from writing them, and keeping
the two apart meant the testing guidance reached a fraction of the people who
needed it.

**Use [anivar/zod-skill](https://github.com/anivar/zod-skill) instead.** The
testing material is at `references/testing.md`, `references/testing-api.md` and
`references/testing-anti-patterns.md`, and the skill triggers on schema-testing
work as well as schema-writing work.

This repository is archived and kept for history only.
